# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via [GitHub Security Advisories](https://github.com/mickaelrebeau/hugeicons-animated-vue/security/advisories/new).

Include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Affected versions and environment (browser, Vue, `motion-v`)

You should receive an acknowledgement within 7 days. If the report is accepted,
a fix will be prepared and a new release published before details are disclosed.
